# Supplementary materials

Supplementary materials for **Waiting time reverses re-pressurization yield rankings in polymer hydrogen-storage liners**.

- `supplementary_methods.pdf`: supplementary methods (20 pages).
- `Supplementary_Data_and_Code.zip`: existing numerical extracts, plotted data, provenance records and plotting scripts.
- `JES_v3_figures.zip`: figure artwork in PDF, SVG, PNG and TIFF formats.
- `SHA256SUMS.txt`: SHA-256 checksums for the four other files in this repository.

The archives do not include the full solver or all original preparation/waiting checkpoints. Plotting scripts use the original research directory layout.
